# 📊 Hotel & Traveler Analysis Dashboard | Tableau

## 📌 Project Overview

This project presents an interactive **Hotel & Traveler Analysis Dashboard** created using Tableau.

The dashboard analyzes hotel performance, traveler behavior, hotel ratings, room capacity, user continents, traveler types, period of stay, and additional hotel services.

## 🎯 Project Objective

The main objective of this project is to explore hotel and traveler data and convert it into meaningful insights through interactive data visualizations.

## 🛠️ Tools & Technologies

- Tableau
- Data Analysis
- Data Visualization
- Dashboard Design
- CSV Dataset

## 📂 Dataset

**Dataset Source:** Tripadvisor

The dataset contains information related to hotels, travelers, reviews, ratings, room capacity, traveler types, continents, period of stay, and hotel facilities.

## 🔍 Key Insights

- Total Hotels – 21
- Average Number of Rooms – 2,196
- Average Hotel Score – 4.123
- Users analyzed by continent
- Traveler types analyzed
- Period of stay analyzed
- Hotel facilities and additional services analyzed
- Top hotels based on total rooms
